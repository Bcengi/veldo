# Icon and Wordmark

`Icon` draws the shell's few line icons (`runs`, `decisions`, `you`, `sun`, `moon`, `search`,
`follow`, `key`) on a 24 unit grid, `aria-hidden`; the control around it carries the name.

`Wordmark` is the name in Big Shoulders beside an enamel lamp. `size="lg"` on the sign-in screen.

Add an icon by adding its paths to `Icon.vue`; keep 1.75 stroke and round joins. No icon font.
