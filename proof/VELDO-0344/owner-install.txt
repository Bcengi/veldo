VELDO-0344, the process reader: what only the owner can do

Nothing below was run by the builder: it needs sudo, and the builder has none. Until it is run, the
reader's state is absent and every process the probe cannot read is judged by the bound, as before.

THE COMMANDS, from the root of the authority checkout, in one shell

1. No sudo. Builds from the blob of C and prints the digest. It must print H:

d=$(mktemp -d) && g=$(id -gn) && /usr/bin/git --no-replace-objects cat-file blob 705d64311de90f1945d7d0c0a5b9b3e6d125e78e:scripts/veldo_procread.c > "$d/veldo_procread.c" && (cd "$d" && env -i PATH=/usr/bin:/bin /usr/bin/cc -std=c11 -O2 -Wall -Wextra -Werror -static -ffile-prefix-map="$d"=. -o "$d/veldo-procread" veldo_procread.c) && sha256sum "$d/veldo-procread"

2. The one sudo command. Root installs, compares with H, and only then sets the capability:

sudo sh -c "install -D -m 0750 '$d/veldo-procread' /usr/local/lib/veldo/veldo-procread && chown root:'$g' /usr/local/lib/veldo/veldo-procread && chmod 0750 /usr/local/lib/veldo/veldo-procread && echo 'bb9bd262a12793669e19a1cf3c77f2539ad48cb26093ba4377d5cf520d70d035  /usr/local/lib/veldo/veldo-procread' | sha256sum -c - && setcap cap_sys_ptrace=ep /usr/local/lib/veldo/veldo-procread" && rm -r "$d"

3. No sudo. The two user units and the socket:

python3 -I .veldo/control_space_probe.py reader-units && systemctl --user daemon-reload && systemctl --user enable --now veldo-procread.socket

4. In the installation's space section (installation.yaml), add the key, quoted as a string:

  process_reader: "bb9bd262a12793669e19a1cf3c77f2539ad48cb26093ba4377d5cf520d70d035"

5. The reader check. It must print "state used cap=1" and four PASS lines, and exit 0:

python3 -I .veldo/control_space_probe.py reader

6. The installed row of AC6, which runs the same check under the authority unit's properties
   (NoNewPrivileges=yes) and is skipped on a host without the reader:

python3 scripts/selftest.py --suite 141_veldo_0344_process_reader

   Its line "VELDO-0344 ac6/installed: ..." carries how long the reader ran. This row is the first
   proof of three things the design marks as assumptions: that cap_sys_ptrace, held by the owner's
   uid, reads root-owned entries; that it reads the task entries; and that the two unit files work
   as written (Accept=yes, the capability arriving in the unit). If step 5 or this row fails, undo
   with any one line of the Undo section of docs/veldo-procread-setup.txt; nothing depends on the
   reader being there.
