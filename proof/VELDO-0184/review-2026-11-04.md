## Acceptance criteria, against the production code

AC1. control_agent_config accepts an optional `file_memory` item ({"load": mode}, malformed refused by name);
control_memory_servers' assistant and assistant_codex role save lists it `always` in a new revision.
control_engine_claude `_file_memory` sets `autoMemoryEnabled` true and `autoMemoryDirectory` to the record's
directory in the generated settings file passed as the settings option (flagSettings), pops CLAUDE_CODE_DISABLE_AUTO_MEMORY from the baseline
environment, and control_launch removes it from every other source; nothing else of the baseline changes. A
version whose qualification entry lacks the form is refused missing_evidence:engine_baseline:<version> in
Receiver._file_memory, before acceptance. The Guard reads the init event before the prompt is released for any
run handed the memory and stops it binding_mismatch:engine_memory unless every `memory_paths` value is the handed
directory (normalized); the stop is a configuration_stop with a file_memory_stopped event. A missing directory,
a missing index, or VELDO-0182's refusal of the file_memory part are refused invalid_input:memory:file:absent
before acceptance. The shipped 2.1.281 entry lists the form; qualify.py lists it only when every
FILE_MEMORY_PATTERNS entry is found and otherwise writes `file_memory_unqualified` naming the missing patterns.
The replay fix in control_owner_revisions rebuilds a committed save with its item, so an identical signed
save replays.

AC2. control_engine_codex `_file_memory` adds the directory to sandbox_workspace_write.writable_roots, appends LAYOUT
plus the index (read at the spawn) to developer_instructions after the role's own, and sets
memories.generate_memories and memories.use_memories false. The 0.154.0 record lists the form; `qualification`
lists it only when the binary carries every literal; a record without it is refused before acceptance.

AC3. The launch line {directory, form, index, index_digest, memory_revision, qualification} is written as a wrapper
line right after the identity line; the digest is SHA-256 of MEMORY.md as read at the spawn. Memory reads and
writes are the engine's own tool lines (VELDO-0141). The reported Codex options name developer_instructions by
digest only.
